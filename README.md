## 網站裡有什麼

頂部選單只有四項：**首頁**、**作品庫**、**GitHub**、**關於**。

- **首頁**：先看定位。會顯示目前登錄幾件、其中幾件正式在用；上面放兩件精選，其餘作品在下面用較短的列表帶過。
- **作品庫**：全部案例。可依類型篩選（VBA、網頁、桌面、自動化、資料）。點卡片會進入單件作品頁，裡面有問題、作法、運作方式與步驟。私人倉庫只講思路，不公開原始碼。
- **GitHub**：對照各案例在 GitHub 上的狀態。私人倉只顯示名稱與摘要，不含程式碼。
- **關於**：背景與做事方式：先量問題，再寫工具；沒驗證過的事情不編成「成效」。要聯絡請走這一頁，這裡不放信箱或私人帳號。

## 這些作品在解決什麼

目前登錄 10 件。

### 1. PSI Dashboard（網頁／正式在用／精選）

物料規劃平常要同時核對好幾份表，欄位一對不齊，建議就會歪。這個畫面把供需、在途與建議處置收進同一張主表，規劃人員在一處就能看完一段期間的變化。尚未確認的調整與正式資料分開，避免還沒審核的內容被當成定稿。作品集內附去識別化靜態展示站（`public/psi-dashboard/`，從案例頁開 `/psi-demo`）。

### 2. VSR Dashboard（網頁／正式在用／精選）

簽核時要同時看未交採購、銷售、庫存與滾動預估。網站依最新試算表自動產生圖表與簽核意見，減少「檔是新的、文字還是舊的」。

### 3. Backlog 交期比對（VBA／正式在用／精選）

要比兩份未交訂單、看出哪些提前、延後或新開，過去常得逐列對很久。現在選兩份報表，工具會標出變化並算出差幾天。

### 4. Outlook 附件收取（自動化／正式在用／精選）

報表從信件進來，手動另存容易漏檔或存錯位置。郵件一開會補掃近幾天，並監看指定信件夾；只收下試算表、自動建資料夾、不覆蓋已有檔，讓後面的比對工具找得到檔。

### 5. 採購單數量調整（桌面／正式在用／精選）

離線的 Windows 工具。用出貨清單回寫採購單數量與金額，結果另存新檔、不覆寫原單。適合單據不能送出公司網路的環境。

### 6. Excel 解法室（網頁／實驗）

現場提出的 Excel 問題多半是症狀，不是規格。這個實驗頁用白話訪談先問清楚：資料從哪來、誰會按、失敗時要怎樣，再對到公式或巨集，讓案例可以累積。

### 7. Date Code 檢查（VBA／正式在用）

讀取出貨通知，標出日期碼過舊的批。讓過舊庫存在出貨前被看見，而不是貨出去了才發現。

### 8. PO Backlog合併（VBA／正式在用）

未交訂單有時拆成多份，手工合併容易欄位移位或貼兩次表頭。這個工具先合成欄位一致的一張表，再交給交期比對。

### 9. 資料庫對帳查詢集（資料／正式在用）

把現場反覆在用的對帳與查詢收成可重跑的腳本。交接時不必從個人視窗翻，報表跟系統對不上時，至少有一份共同起點。

### 10. 現場 VBA 工具箱（VBA／持續迭代）

還在現場用、還沒獨立成專案的小工具（對帳、調貨、補單、對照）先收在同一處。穩定後再拆成獨立案例，不把未完成項假裝成已上線產品。

## 怎麼看這個站

- **主管或人資**：先看首頁與兩件精選，再看「關於」。
- **要合作或要對內容**：每件都有標狀態（正式在用、持續迭代、實驗）。現場原始碼多半不公開，拆解步驟在作品內頁。
